# ClassTrack V1.1 架构

## 已锁定的产品行为

- 完全离线，不启用 Wi-Fi、蓝牙、云账号或模型运行时。
- 最多 12 个稳定班级 ID（`0..11`），通过 UTF-8 CSV 导入。
- 每班只有一条可见录音：16 kHz 单声道 IMA ADPCM，通常 15 秒，硬上限 20 秒。
- 新录音在试听阶段保持临时状态。只有“确认保存”才会使它原子地成为当前录音；放弃、重启或掉电都会继续选择上一条已提交录音。
- 首页顶部以中国标准时间显示完整年月日和时分。冷启动时间无效时仍可录音，时间戳标为“待校准”；USB 校时后立即刷新界面并保存真实时间。录音页每秒显示实时进度。

## Flash 布局与事务

| 区域 | 大小 | 用途 |
| --- | ---: | --- |
| NVS + PHY | 64 KiB | 班级 CSV、最近校时标记、ESP-IDF 数据 |
| Factory 应用 | 2.94 MiB | ClassTrack 与 FoloToy 官方 BSP |
| `classdata` | 4.94 MiB | 两个等大的事务音频银行 |
| 尾部预留 | 64 KiB | 不划入任何分区 |

每个音频银行包含一个 4 KiB 头部和十四个固定 168 KiB 槽位。十二个槽位覆盖最大班级数，另外两个吸收替换或放弃产生的事务。每个槽位由带校验的头部、流式 ADPCM 载荷和固定位置的校验尾部组成；四字节提交标记最后写入。启动扫描会忽略头部、尾部、提交标记或载荷 CRC 任一无效的槽位。

活动银行没有空槽时，程序把每个班级最新的已提交录音复制到已擦除的另一个银行。全部复制校验完成后才提交新银行头。此前若重启，旧银行仍保持活动。旧银行不会立刻擦除，直到以后再次作为整理目标。

16 kHz 下，每个独立的 256 样本 ADPCM 块最多使用 132 字节，20 秒共 165,000 字节。编码和播放只使用一个 512 字节 PCM 块和一个 132 字节编码块，不需要申请 640 KiB 的 20 秒 PCM 缓冲。

## USB 串口协议

Mac 管理器与设备使用 ASCII 控制通道和带 CRC 的二进制载荷。设备响应都以 `CT ` 开头，使管理器可以忽略启动日志。

```text
HELLO
TIME <Unix秒>
IMPORT <字节数> <CRC32十六进制>\n<UTF-8 CSV字节>
LIST
GET <班级ID>
```

`GET` 返回 `AUDIO` 头、精确长度的 ADPCM 字节和 `CT DONE`。备份清单记录编码格式、采样率、样本数、时间戳、载荷 CRC 和文件名。导入按声明长度循环接收完整载荷，再验证大小、CRC、表头、ID、UTF-8 长度、重复项，以及 LVGL 当前字体的真实字形覆盖，然后才替换 NVS 中的班级数据；USB 传输期间不会自动深睡。

原生 [Mac 管理工具](mac-manager.zh_CN.md)把手动校时和课表上传整合在一个只在前台运行的应用中。它不安装登录项或后台服务，窗口关闭后进程即退出。

## 低功耗顺序

无输入 30 秒后，且当前不在录音、播放或 Flash 操作中，应用先确认 ADC 按键已松开；随后把 GPIO0 交回数字输入，启用低电平按键唤醒，依次暂停 CW2017 和 ES8311，停止并释放 I2S，释放共享 I2C，等待当前 LVGL 刷屏结束，让 ST7789P3 与背光引脚进入终端睡眠状态，最后进入深睡眠。唤醒后应用重新启动。唤醒键仍被按住时的防误触需要实机验收。

## 240×320 界面与字体

浏览器原型和固件都为顶部双行日期/时间状态栏保留 44 像素，为底部固定按键提示保留 29–30 像素。试听页的四个操作项位于独立双行说明区之上，两者都不能进入页脚。浏览器自动化以真实 240×320 尺寸测量七个页面，检查安全区、实际溢出和元素交叠。

固件使用从 Source Han Sans SC 生成的 ClassTrack 16 px 定制子集，完整覆盖固定界面文字和当前六个班级/课程名，并显式绑定到每个标签。CSV 导入会拒绝当前字体不包含的字形，避免接受后才显示方框；最终像素效果仍必须用实体屏幕验证。

CW2017 唤醒后需要连续三个稳定 SOC 读数。电芯电压仍高于 3.6 V 时拒绝瞬态 0%，运行中大幅跳变也要连续三次确认，避免顶部电量偶尔从 90% 以上闪成 0%。

## 必须完成的实机验收

1. 在 ST7789P3 上检查所有固定中文和示例班级名，包括圆角、长名称、选中状态以及试听说明与页脚间距。
2. 测量上、下、OK 三键 ADC 电压，确认短按 OK 开始录音、再按 OK 停止。
3. 完成录音、试听、放弃、确认；分别在录制时和提交前断电，确认所有未提交情况都保留旧录音。
4. 确认采样率正确、麦克风非零、ADPCM 语音可懂，并监听 Flash 保存时是否有杂音。
5. 写满足够槽位以触发银行整理，在整理各阶段复位，确认每班最新已提交录音仍正确。
6. 验证校时、CSV 导入、备份、冷启动时间无效提示；在宣称“备份可恢复”前还要补充恢复工具。
7. 测量运行、息屏和深睡电流，执行 24 小时、72 小时和一周测试，并检查按键唤醒及时间漂移。
