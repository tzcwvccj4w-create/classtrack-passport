# ClassTrack V1.1 完整工程包

打包日期：2026-10-29  
目标设备：FoloToy AI Passport，ESP32-C3、8 MB Flash、无 PSRAM  
固件框架：ESP-IDF 5.5.3

这是 ClassTrack（课到哪了？）当前最新工程快照。它位于独立项目中，没有修改用户的家庭教育 GitHub 仓库。

## 目录说明

- `main/`：ClassTrack 页面、状态机、录音、ADPCM、班级、USB 协议和事务存储源码。
- `components/bsp/`：FoloToy AI Passport 显示、ES8311、ADC 按键、电量计和低功耗 BSP。
- `assets/`：ClassTrack 中文字体、字形清单和界面资源。
- `managed_components/`：本次工程所用的 ESP-IDF 管理组件源码，可减少离线复现时的依赖缺失。
- `prototype/`：七页 240×320 交互原型、自动布局测试和最新截图。
- `dist/ClassTrack 管理工具.app`：可随开随关的原生 Mac 前台应用。
- `dist/ClassTrack-Manager-macOS.dmg`：拖入“应用程序”即可安装的镜像。
- `tools/classtrack_manager.py`：可选命令行管理与录音备份工具。
- `examples/classes.csv`：六条当前课表数据示例。
- `tests/`：ClassTrack 和 FoloToy BSP 的主机自动化测试。
- `build/FoloToy-AI-Passport-full.bin`：从 `0x0` 写入的完整固件。
- `build/firmware/1d1fa86...e0be/`：与完整固件严格匹配的应用镜像、ELF、MAP、bootloader、分区表、刷写参数和清单。
- `records/`：测试与实机验证记录。

## 已完成

- 七个页面的 240×320 安全区、中文字形、溢出和元素相交检查通过；“保存前试听”页重叠已修复。
- 内置六个班级/课程，支持最多 12 个班级；每班仅保留一条最长 20 秒录音。
- 16 kHz 单声道流式 IMA ADPCM；无需申请 20 秒 PCM 大缓冲。
- 双银行 Flash 事务、提交标记、CRC、旧录音替换和银行整理逻辑已实现并通过主机故障注入测试。
- 录音页按秒更新的代码和主机契约测试已完成。
- 顶部双行显示完整年月日和时分，固定使用中国标准时间；USB 校时后立即刷新。
- CW2017 三次稳定采样、高电压下拒绝瞬态 0%、大幅跳变确认逻辑已实现。
- 原生 Mac 应用集成设备发现、手动校时、课表预览/选择和 CSV 上传；关闭窗口即退出，不设置后台服务。
- 可选命令行工具支持状态、校时、CSV 导入和 ADPCM 备份协议，且不再依赖 `pyserial`。
- 固件已成功编译、合并并校验；同一镜像已刷入设备并通过启动及外设初始化检查。
- 已通过命令行管理器在实机上验证 USB `HELLO`、Mac 手动校时和六条 CSV 导入；启动时电池稳定读数为 92% / 4097 mV。

## 尚未完成或尚未经过完整实机验证

- 录音页 `00:01`、`00:02` 的实体屏幕变化，以及第二次按 OK 停止录音，仍缺用户目视确认。
- ES8311 麦克风输入、试听音质、音量、ADPCM 回放可懂度及 Flash 写入噪声尚未完成全流程验收。
- 录制、提交和银行整理期间断电后的数据保留，仅有主机故障注入测试，尚未在实机逐阶段断电验证。
- 最终固件在实体 ST7789P3 上的完整日期排版、长班级名和页脚间距尚未拍照复核。
- 新图形化 Mac 应用的“同步 Mac 当前时间”和“上传课表到设备”按钮尚未对连接且唤醒的实机完成验收；命令行管理器的 `status`、手动校时和 CSV 导入已实机通过。
- `backup` 的完整端到端读取尚未实机通过。
- 当前只有备份工具，没有把备份恢复到设备的恢复命令，因此不能宣称“备份可恢复”。
- 设备菜单中的“Mac USB 校时”会向 Mac 请求时间；按用户选择，本项目不安装常驻后台程序。需要校时时打开管理应用并点击同步即可。
- 深睡电流、按键唤醒边界、24/72 小时及一周运行、时间漂移尚未完成。
- 电量误报 0% 的过滤逻辑和启动 92% 读数已验证，但仍需长期运行确认不再偶发。
